LocoNotas is a notebook, not a project site. It holds dated observations, reading notes, experiment logs, and ideas that are still moving.

## What belongs here

- Reading notes on books, papers, videos, and articles
- Experiment logs with a command line and a result
- Field notes about hardware, drivers, thermals, and failures
- Explainers that other pages can link to
- Book notes and chapter notes

## What does not belong here

- Stable project documentation. That lives on each project site.
- Formal papers, preprints, and grant outputs. Those live on [research.borck.dev](https://research.borck.dev).
- Anything that needs to be maintained as a reference. Promote it to a project page once it settles.

## Note types

| Type | Use |
|---|---|
| `reading-note` | A book, paper, video, or article |
| `experiment` | A dated test with a command line and a result |
| `field-note` | An observation, failure, or hardware quirk |
| `explainer` | A stable explanation that other pages link to |
| `book-note` | Notes on a specific book or chapter |

## Status labels

| Status | Meaning |
|---|---|
| `draft` | Not ready to read |
| `published` | Written, not necessarily verified |
| `unverified` | An external claim we have not checked |
| `verified` | Checked against a primary source or a measurement |
| `superseded` | Replaced by a newer note |
