# LocoNotas

Field notes from the floor: reading notes, experiments, and observations from LocoLabo.

Site: https://loconotas.org

## What belongs here

Dated notes that do not belong in a project's reference docs: reading notes, experiment logs, field notes, and explainers. Formal papers live on [research.borck.dev](https://research.borck.dev). Stable documentation lives on each project site.

## Local development

```bash
npm install
npm run dev
```

## Deploy

Push to `main`. The `Deploy to GitHub Pages` workflow builds the Starlight site and publishes it.
